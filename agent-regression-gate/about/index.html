About

Private beta

Anubys is a CI-native agent regression harness.

It runs in the pull request. The candidate and the baseline face the same scenarios, and the merge gets a statistics-backed check.

The problem

Regressions stay quiet.

An LLM agent can regress when a model, prompt, or tool changes. Ordinary tests miss the drop. Reading a few transcripts misses it too. Teams ship without a signal, or they hold the change on too little evidence.

What Anubys does

A merge check, with a verdict.

In CI, Anubys runs the candidate and the baseline on paired scenarios. The pull request receives one statistics-backed verdict.

  • Pass

  • Block

  • Insufficient evidence

  • Invalid run

    Technical details

    The adapter contract is provider-agnostic, and it is the intended seam. Gemini is the only adapter today. One rollout is one call: scenario id, SHA-256 of the scenario text, arm (baseline or candidate), and a step budget. The adapter returns pass, fail, agent timeout, agent error, or an infrastructure miss. A live rollout that goes over its dollar ceiling is recorded as an error with reason spend_ceiling. An agent timeout, an agent error, and a spend-ceiling error each score 0 and stay in the pass rate. A provider error, a rate limit, or a killed runner is excluded from the score and counted toward the 5% miss cap. The model name does not enter the suite verdict.

    Gemini today. The harness calls a pinned Gemini Flash-Lite model id (lives in config/allowed_models.txt and is passed with --model). A floating alias is not the pin, because it moves. The Gemini adapter is Built. OpenAI and Claude are planned for v0.2, after the November 30 release. They are not partnerships, and they are not backends in this repository today.

    The scorer does not import an agent SDK. It pairs scenarios, builds the 90% interval, and the check fails on Block. Scenario rows stay diagnostics. They are not individual gates.

    GitHub Action, planned for v0.2, after the November 30 release. Trigger pull_request so the check can be required. The job runs both arms through the adapter and uploads results.json. It fails the check on Block. An invalid run is reported as invalid and isn't scored. A merge queue would also need the merge_group event. Buildkite, Jenkins, and your own runner are the same planned job, not separate products.

    Cassette replay is Built. Record mode stores model and tool traffic keyed by a hash of each model request. Replay mode returns that recording and does not call the provider. You need your own --record first. No sample recording ships. A hash mismatch is a miss, not a silent reuse. A cassette is an input to scoring. It is not a verdict.

    OpenTelemetry is Planned post-MVP. If an agent already emits GenAI spans, an adapter may attach the trace as a diagnostic. Spans do not set the suite status. Those semantic conventions are still marked Development. Inspect, promptfoo, LangSmith, Braintrust, and DeepEval are planned sources of scenarios or scores. They do not become the suite verdict.
